# MemoCut

Програма для Windows, яка сама монтує відео за ТЗ: вибирає шматки з сирих відео,
накладає заголовки й субтитри у вибраному стилі та робить 3 варіації на вибір.
Працює повністю на вашому комп'ютері, без інтернету й без ШІ.

## Встановлення
1. На GitHub: вкладка **Actions** → останній запуск «Build Windows» → завантажити `MemoCut-windows.zip`
   (або вкладка **Releases**, якщо випущено версію).
2. Розпакувати в будь-яку папку, напр. `C:\MemoCut`.
3. Усередині: `MemoCut.exe` (програма), `memocut-cli.exe` (для командного рядка), папки `ffmpeg`, `styles`, `briefs`.

## Як користуватися
1. Запустіть `MemoCut.exe` (або перетягніть файл ТЗ `.yaml` на нього).
2. **Вибрати ТЗ…** → перевірте сегменти, стиль і кількість варіацій → **Змонтувати**.
3. Дочекайтеся кінця (можна скасувати). З'являться прев'ю всіх варіацій: клік по відео — відтворення.
4. На варіації, що подобається, натисніть **Експорт MP4** — збережеться `final.mp4` у повній якості
   (можна натиснути на кількох — вони відрендеряться по черзі). **Папка** відкриває її в Провіднику.
5. **Відкрити готові результати…** — повернутися до вже змонтованого без повторного монтажу.

Журнал помилок: `%LOCALAPPDATA%\MemoCut\memocut.log`.

## Командний рядок
Відкрийте папку з програмою, у рядку адреси Провідника наберіть `cmd` і Enter.

```
memocut-cli run "D:\Відео\ТЗ\промо1.yaml"
```
Програма проаналізує папку з сирими відео й створить поруч із ТЗ:
```
output\Назва\var1\preview.mp4
output\Назва\var2\preview.mp4
output\Назва\var3\preview.mp4
```

### Правки
```
memocut-cli show   "output\Назва\var2"              — список сегментів і альтернатив
memocut-cli alt    "output\Назва\var2" s2 0         — замінити сегмент s2 на альтернативу [0]
memocut-cli trim   "output\Назва\var2" s2 1.5 4.0   — обрізати сегмент s2 (секунди у файлі)
memocut-cli replace "output\Назва\var2" s2 IMG_0412.mp4   — поставити інший файл
memocut-cli render "output\Назва\var2" --final      — фінальне відео в повній якості
```
Кожна правка зберігається в `history\`, тож можна повернутися до будь-якої версії.

## Як писати ТЗ
Див. `briefs/example.yaml`. Кожен сегмент — один з трьох видів:
- `clip: файл` + `start`/`end` — точний шматок;
- `find: "фраза"` — знайти, де це кажуть (потрібен транскрипт);
- `any: true` — будь-який якісний фрагмент (світлий, без тиші, в межах однієї сцени).

## Транскрипти
Якщо поруч із відео лежить `IMG_0412.srt` або `IMG_0412.words.json` — береться він.
Інакше програма розпізнає мову сама (перший раз качає модель ~500 МБ).

## Стилі
Файли в `styles\`. Скопіюйте `couples_warm.yaml`, перейменуйте й змініть кольори, розміри,
анімацію (`fade`, `pop`, `slide`, `none`). У ТЗ вкажіть `style: назва_файлу`.
